# Slide Transitions — Phase 1 (No Morph)

This folder contains the **implementation-ready specifications** for Slide Transitions **Phase 1**.

**Phase 1 includes:**
- Cross fade
- Wipe (directional)
- Push (directional)
- Cover (directional)
- Uncover (directional)

**Explicitly out of scope for Phase 1:**
- Morph / Smart Animate (Phase 2)
- Zoom, 3D, page curl, etc.
