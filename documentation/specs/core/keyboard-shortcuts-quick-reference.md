# Keyboard Shortcuts - Quick Reference

This is a condensed view of the authoritative spec in `keyboard-shortcuts.md`.

Canonical ledger: `documentation/specs/core/keyboard-shortcuts-ledger.md`


## Essentials

### Tools
| Key | Action |
|---:|---|
| `V` | Select / Move |
| `H` | Hand (pan) |
| `T` | Text tool |
| `R` | Rectangle |
| `O` | Ellipse |
| `L` | Line |
| `Shift+L` | Arrow |
| `Shift+I` | Toggle Resources (Icon Library) |
| `Shift+K` | Image tool |

### Edit
| Shortcut | Mac | Windows |
|---|---|---|
| Copy | `⌘C` | `Ctrl+C` |
| Paste | `⌘V` | `Ctrl+V` |
| Duplicate | `⌘D` | `Ctrl+D` |
| Delete | `⌫` | `Del` |
| Undo | `⌘Z` | `Ctrl+Z` |
| Redo | `⌘⇧Z` | `Ctrl+Shift+Z` |

### Panels
| Shortcut | Action |
|---|---|
| `Cmd/Ctrl+Shift+C` | Toggle Color Theme manager |
| `Cmd/Ctrl+Shift+T` | Toggle Typography Style manager |
| `Cmd/Ctrl+Shift+K` | Toggle Code Fill panel |

### Arrange
| Shortcut | Mac | Windows |
|---|---|---|
| Bring forward | `⌘]` | `Ctrl+]` |
| Send backward | `⌘[` | `Ctrl+[` |
| Bring to front | `⌘⇧]` | `Ctrl+Shift+]` |
| Send to back | `⌘⇧[` | `Ctrl+Shift+[` |
| Group | `⌘G` | `Ctrl+G` |
| Ungroup | `⌘⇧G` | `Ctrl+Shift+G` |

### Nudge
```
Arrows         - Nudge 1px
Shift + Arrows - Nudge 10px
```

---

## Text editing
```
Esc              - Exit text edit
Cmd/Ctrl + Enter - Exit text edit (commit)
Cmd/Ctrl + B     - Bold
Cmd/Ctrl + I     - Italic
Cmd/Ctrl + U     - Underline
Cmd/Ctrl + Shift + X - Strikethrough
Tab (not in list)     - Exit text edit, select next element
Tab/Shift+Tab (in list) - Indent/Outdent
```

---

## Presentation
```
Esc - Exit presentation
Next: ArrowRight / Space / Enter / PageDown / N
Prev: ArrowLeft / Backspace / PageUp / P
B or . - Black screen
W or , - White screen
L - Laser
G - Grid view
```

---

## Global
```
Cmd/Ctrl + N         - New
Cmd/Ctrl + O         - Open
Cmd/Ctrl + S         - Save
Cmd/Ctrl + Shift + S - Save as
Cmd/Ctrl + Shift + M - Toggle Master mode
```
