## Tips & Tricks

### Hold Keys for Temporary Tools
- Hold `Space` → Hand tool (release to go back)
- Hold `Z` → Zoom tool
- Hold `Cmd/Ctrl` while clicking → Deep select into groups

### Modifiers During Actions
- Hold `Shift` while drawing → Perfect square/circle
- Hold `Alt` while resizing → Resize from center
- Hold `Shift` while resizing → Maintain aspect ratio
- Hold `Shift+Alt` while resizing → Center + constrain

### Smart Nudging
- `Arrows` → Move 1px
- `Shift + Arrows` → Move 10px
- `Cmd/Ctrl + Arrows` → Move by grid increment

### Quick Duplication
- `Cmd/Ctrl + D` → Duplicate in place
- `Alt + Drag` → Duplicate while moving

### Navigation
- `Tab` → Select next sibling
- `Shift + Tab` → Select previous sibling
- `Enter` → Select child (into group)
- `Shift + Enter` → Select parent

## Context-Specific Shortcuts

### When Text Editing
Standard text editing applies:
- `Cmd/Ctrl + A` → Select all text
- `Cmd/Ctrl + B/I/U` → Bold/Italic/Underline
- `Arrows` → Move cursor
- `Shift + Arrow` → Select text
- `Esc` → Exit text edit

### When In Presentation Mode
- `→`, `Space`, `Page Down` → Next slide
- `←`, `Page Up` → Previous slide
- `Home` → First slide
- `End` → Last slide
- `Esc` → Exit presentation
- `B` → Black screen
- `W` → White screen
- `[Number] + Enter` → Jump to slide

### When Selecting Multiple Objects
- `Cmd/Ctrl + ]` → Bring all forward
- `Cmd/Ctrl + [` → Send all backward
- `Cmd/Ctrl + G` → Group selection
- `Alt + A/W/H/T/S/V` → Align objects

## Learning Path

### Beginner (Week 1)
1. Learn tool shortcuts: `V`, `R`, `T`, `H`
2. Learn basic edit: `Cmd/Ctrl + C/V/Z/S`
3. Learn zoom: `Cmd/Ctrl + 0/1`, `Space + Drag`

### Intermediate (Week 2-3)
1. Learn arrange: `Cmd/Ctrl + ]/[`
2. Learn group: `Cmd/Ctrl + G`
3. Learn duplicate: `Cmd/Ctrl + D`, `Alt + Drag`
4. Learn nudging: `Arrows`, `Shift + Arrows`

### Advanced (Week 4+)
1. Learn alignment: `Alt + A/W/H/T/S/V`
2. Learn all tools: `O`, `L`, `P`, `F`, `K`, `I`
3. Learn modifier combinations: `Shift`, `Alt`, `Cmd/Ctrl`
4. Learn text formatting: `Cmd/Ctrl + B/I/U`
5. Learn presentation shortcuts
