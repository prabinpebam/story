Selection Hiding Behavior - Manual Test

Test 1: Rectangle Selection HidingPENDING

Expected Behavior:
  1. Select a rectangle element in the main app
  2. Open Property Inspector and adjust X/Y position using scrubbing
  3. While scrubbing, the selection box should disappear
  4. When you release the mouse, selection should reappear

Test 2: Text Selection ExceptionPENDING

Expected Behavior:
  1. Select a text element in the main app
  2. Open Property Inspector and adjust X/Y position using scrubbing
  3. While scrubbing, the selection box should remain visible
  4. This is different from rectangles - text always shows selection

Test 3: Multi-Selection (No Text)PENDING

Expected Behavior:
  1. Select multiple rectangles/circles (NO text elements)
  2. Adjust properties using scrubbing
  3. While scrubbing, selection overlays should disappear
  4. After releasing, selection should reappear

Test 4: Multi-Selection (With Text)PENDING

Expected Behavior:
  1. Select multiple elements including at least one text element
  2. Adjust properties using scrubbing
  3. While scrubbing, selection overlays should remain visible
  4. Text presence overrides hiding behavior

Test 5: Performance (No Jitter)PENDING

Expected Behavior:
  1. Select any element
  2. Rapidly scrub position/size properties back and forth
  3. Movement should be smooth with no stuttering
  4. No visible lag or "sticking" behavior
  5. Selection hide/show should be instant (no flicker)
